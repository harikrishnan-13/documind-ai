# DocuMind AI – Intelligent Document Assistant

An AI-powered document intelligence application built using Python, Django REST Framework, React, Microsoft SQL Server, ChromaDB and OpenAI.

## Project Objective

DocuMind AI allows users to upload PDF and DOCX documents, ask natural-language questions, generate document summaries and receive AI-powered responses with source citations.

## Technology Stack

**Frontend**
- React.js
- Vite
- Tailwind CSS

**Backend**
- Python
- Django
- Django REST Framework

**Databases**
- Microsoft SQL Server
- ChromaDB

**AI Engineering**
- OpenAI API
- LLMs
- Embeddings
- Retrieval-Augmented Generation (RAG)
- LangChain

**Background Processing**
- Celery
- Redis

**DevOps**
- Git
- GitHub Actions
- Docker

## Architecture

The application follows a modular full-stack architecture with separate frontend, backend, AI services and database layers.
